The preoperative model provides an initial risk estimate using information available before surgery. The pre-catheter-removal model updates the estimate by incorporating concomitant hysterectomy and estimated blood loss.

Model equations and coding
Preoperative model logit(p) = -0.7018527 - 0.1320437 × BMI + 2.0333829 × incomplete emptying + 2.0792384 × detrusor thickening Pre-catheter-removal model logit(p) = -2.3657412 - 0.1442083 × BMI + 2.0103388 × incomplete emptying + 1.8763057 × detrusor thickening + 1.9516334 × concomitant hysterectomy + 0.0051726 × estimated blood loss Binary predictors are coded as Yes = 1 and No = 0. Continuous predictors are entered in their original units.
The calculator uses pooled logistic regression coefficients obtained after multiple imputation. Internal validation was performed using 1,000 bootstrap repetitions. Predictions outside the ranges represented in the development data should be interpreted with additional caution.
